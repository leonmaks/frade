Параметры производительности и надежности

performance
Параметры производительности системы / сервиса. В зависимости от реализуемой функциональности, производительность может содержать информацию о количестве запросов, времени обработки одного запроса, времени чтения, записи, вставки и удаления объектов данных в системе или иные показатели, характеризующие производительность. В общепринятой практике, параметры производительности системы подтверждаются нагрузочным тестированием. Для внешних систем / сервисов, обычно, производительность фиксируется в Договоре об уровне сервиса (SLA).
rto
RTO (recovery time objective) - период времени (в часах), в течение которого система гарантированно должна быть восстановлена после сбоя / выхода из строя автоматизированной системы / функциональной подсистемы / сервиса.
rpo
RPO (recovery point objective) - максимальный период времени (в часах), за который могут быть потеряны данные в результате сбоя / выхода из строя автоматизированной системы / функциональной подсистемы / сервиса.
sla
Уровень доступности, которому должна удовлетворять автоматизированная система / функциональная подсистема / сервис. Уровень доступности рассчитывается как отношение времени, когда система должна полностью функционировать в рамках определенного временного периода к длительности этого временного периода. Обычно в качестве периода принимается 1 год. Уровень доступности выражается в процентах.
monitoring
Средства мониторинга, применяемые для данного объекта

В качестве значений должны использоваться значения соответствующего справочника. \n - "Отсутствует" если резервирование не реализовано ни для одного из компонентов объекта \n - "Частичное" если: \n * резервирование реализовано не для всех компонентов объекта, \n * либо для некоторых компонентов вычислительные мощности зарезервированы не в полном объеме, \n * либо для statefull компонентов данные зарезервированы не в полном объеме \n - "Полное" если вычислительные мощности зарезервированы в полном объеме для всех компонентов, и для statefull компонентов данные зарезервированы в полном объеме
