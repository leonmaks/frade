# Development

From the monorepo root, run `pnpm install --frozen-lockfile`, then `pnpm dev:draw`. Use `pnpm test` for Vitest, `pnpm typecheck` for TypeScript, `pnpm build` for Vite production output, and `pnpm test:e2e` for Playwright Chromium. Keep changes in the OpenSpec task order and add a regression test for each routing defect.
