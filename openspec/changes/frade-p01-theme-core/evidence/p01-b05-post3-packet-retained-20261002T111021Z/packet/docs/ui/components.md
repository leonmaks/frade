# Native UI component contract

Applicable foundation rules: FDS-003/008/009/010/015–018; A11Y-001/002/008 for token contrast and forced-colors data. The audit maps every FDS/A11Y target to current code; this document specifies adoption contracts, not completed migrations.

Frade is a personal architectural workshop: restore actual context, identify the focused object, show truthful save/dirty feedback, leave diagrams readable. Avoid decorative urgency, unsupported actions and fake AI/provider feedback. Preserve current textual Frade mark, Codicon font/license and domain assets.

Reuse native React/HTML controls first. Workbench.tsx owns shell, tabs, menus, palette and modal structures; Navigator.tsx owns its tree; Inspector.tsx owns forms/reference picker; FlowManager.tsx owns flow lists; FradeDiagramView/DiagramView own native/embedded hosts. There is no existing general headless library or unified overlay host. Foundation does not create one.

Every new shared component must record anatomy, variants, sizes, state intersections, keyboard, accessible names/roles, token mapping and meaningful examples/tests in its change. Light/Dark/HC/System and compact/comfortable are presentation contracts, not current runtime settings.

Dependency direction: UI features → existing shared patterns → semantic CSS variables/static data. ui-workspace already depends on navigator and inspector; neither may import ui-workspace. They inherit root variables without adding a reverse package edge. A code-level shared-control extraction needs its own reviewed minimal leaf design. Foundation exports only generated data/CSS, adds no runtime imports or dependencies, and preserves existing boundary checks.

Known gaps remain in the [migration inventory](migration.md); legacy exceptions record exact occurrence, reason and closing stage. Do not recolor user/domain paint to clear a UI check.
