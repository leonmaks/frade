# Controlled behaviorless RED replay

These files are a deliberately behaviorless API skeleton for portable replay of the final tests. They were created during the 2026-10-02 repair and are **not** the original preimplementation bytes. The immutable original seed, original tests-only snapshot, and historical chronological RED/GREEN logs remain in the authorized input. Copy this `scripts/directions` tree and the files from `deliverables/repair-red/tests` into a separate scratch project, removing the `.snapshot` suffix from the test filenames. The suffix keeps `node --test` in the work tree from discovering these evidence copies. The skeleton replay failures are recorded in `logs/controlled-skeleton-red.tap`; the final tests replayed against exact pre-fix production bytes are in `logs/prefix-final-tests-red.tap`. The earlier chronological repair RED is in `logs/repair-red-direct.tap`. None of these later controlled replays are claimed as original preimplementation bytes or original chronological RED.
