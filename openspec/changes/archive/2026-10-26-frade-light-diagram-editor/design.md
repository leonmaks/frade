## Goals / Non-Goals

**Goals:** one upstream style authority, scoped native adapter, fixed Light independent from external theme/density, preserved owner/content/system/transaction contracts, bounded current evidence and two-stage delivery.

**Non-Goals:** replacing React/X6, equal feature sets or whole-screen pixel identity; new library/icon family/settings/resolver, remote resources, route/action/document/schema/vendor/brand changes. Upstream maturity is not Frade integration proof or blanket accessibility certification.

## Risks / Trade-offs

- Different DOM/global engine CSS: parser-based scoped mapping, exhaustive consumption/exclusion manifest and leakage negative checks.
- Stock forced-color suppression: verify actual system precedence, retain minimal named adaptations.
- Missing native equivalent: report unsupported capability, never claim universal pixel parity or add engine features.
- Legacy pins bind old visuals: exact reversible per-assertion source maps and preserved origins.
- Faster delivery misses integration: explicit representative matrix and per-check PASS/FAIL/BLOCKED/NOT_RUN.
