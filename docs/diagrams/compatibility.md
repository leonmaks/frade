# Диаграммы репозитория: форматы и совместимость

## Решение

В одном репозитории поддерживаются два независимых формата:

| Файл                                                     | Редактор                 | Назначение                                                                            |
| -------------------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------- |
| `.drawio`                                                | Локальный Draw.io 31.5.2 | Обмен обычными документами Draw.io без преобразования в X6                            |
| `.frade`                                                 | Frade Draw / X6          | Управляемая интеграция с объектами, события узлов, NRT и развитие специальных функций |
| Native Draw.io XML с другим расширением, например `.xml` | Локальный Draw.io        | Открытие по содержимому; `.frade` зарезервировано для JSON Frade                      |

Оба редактора используют один файловый API, `_diagrams`, обычные вкладки, ревизии и сохранение. Переименование не преобразует XML в JSON: смена расширения между `.frade` и другим форматом отклоняется. Автоматического конвертера между форматами нет.

## Что значит совместимость с Draw.io

Максимальная практическая совместимость достигается использованием самого Draw.io. Конвертация в X6 не может гарантированно перенести произвольные библиотеки фигур, структуру страниц, слоёв, XML-метаданные и все стили/поведения mxGraph. Поэтому `.drawio` не проходит через модель Frade Draw.

**Универсальную стопроцентную совместимость обещать нельзя**, даже при оригинальном движке. Она зависит от версии, ресурсов, плагинов, браузера, шрифтов и доступных серверных функций. Мы обеспечиваем редактирование поддерживаемых локальным движком документов, а не воспроизводим все интеграции сайта diagrams.net.

| Область                                                                        | Поддержка и граница                                                                                                                              |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `mxfile`, `mxGraphModel`, обычный XML                                          | Native загрузка/сохранение оригинальным движком                                                                                                  |
| Сжатые страницы Draw.io                                                        | Принимаются; после редактирования сохранение может стать несжатым XML                                                                            |
| Несколько страниц, слои, группы, геометрия, порты, соединители, точки маршрута | Обрабатываются самим Draw.io; отсутствует перевод в пять фигур X6                                                                                |
| Стандартные стили, rich text, встроенные библиотеки                            | Возможности закреплённой версии; проверка на представительных документах, не доказательство всех комбинаций                                      |
| Дополнительные данные `UserObject`                                             | Frade хранит `fradeObjectId` и опциональный `fradeSourceId`; обычный Draw.io может редактировать документ без Frade                              |
| Произвольные неизвестные XML-расширения                                        | Побайтовое и семантическое сохранение всех неизвестных конструкций не обещается: сериализацией управляет Draw.io                                 |
| Открытие без изменений                                                         | Исходный файл не переписывается. Save без изменений не нормализует файл                                                                          |
| После изменений                                                                | XML может измениться: форматирование, порядок атрибутов, служебные поля, сжатие. Это не побайтовый roundtrip                                     |
| Картинки, включённые в документ как `data:`                                    | Доступны без сети; отображение зависит от поддерживаемого формата                                                                                |
| URL изображений, веб-шрифты, внешние CSS и сетевые библиотеки                  | Сетевые запросы редактора заблокированы. Ресурс может не отображаться; его ссылка не загружается автоматически                                   |
| Локальные шрифты                                                               | Зависят от установленных шрифтов. Идентичность пикселей на разных компьютерах не гарантируется                                                   |
| Пользовательские executable plugins                                            | Отключены; нужная плагину семантика/рендеринг не гарантируются                                                                                   |
| Облачные хранилища, live collaboration, аккаунты                               | Не входят в интеграцию. Документ хранится в репозитории                                                                                          |
| Экспорт через сервер, например часть PDF/рендеринг                             | Серверы не подключены. Доступность локальных SVG/PNG зависит от движка и содержимого                                                             |
| `.drawio.png`/SVG с вложенным XML                                              | Сам Draw.io умеет такие форматы, но файловый backend Frade сейчас принимает XML/JSON. Для работы через дерево сохраните их в `.drawio` в Draw.io |
| Обычная картинка PNG/SVG без модели                                            | Это изображение, а не редактируемые графовые объекты                                                                                             |
| Visio, Gliffy, Lucidchart и другие импорты                                     | Не являются обещанием нативной совместимости; преобразование стороннего формата может терять возможности                                         |
| Новые версии Draw.io                                                           | Документ может содержать неизвестные закреплённой версии функции. Обновление движка требует повторного roundtrip-тестирования                    |

Предохранители текущего файлового API: UTF-8, файл до 4 МиБ, до 100 страниц; для сжатых страниц суммарно до 16 МиБ распакованного XML, глубина XML до 128. XML с DTD не принимается. Дерево ограничено 2000 записями и 32 компонентами пути; превышение даёт ошибку, а не молчаливую частичную запись.

## Интеграция объектов и NRT

Draw.io **не запрещает** интеграцию с репозиторием или NRT. Его embed-протокол предоставляет загрузку, autosave, export, merge, действия и другие сообщения. Однако контракт обмена документами отличается от прямого доступа к модели X6 и её событиям. Для подробных событий, доменных правил и полностью управляемого UX собственный Frade Draw удобнее; это выбор архитектуры, а не абсолютная невозможность сделать NRT в Draw.io.

Первая реализация `.frade`:

- Узлы имеют валидируемый `repositoryRef: { objectId, sourceId? }`. Без `sourceId` ссылка относится к репозиторию файла.
- Объекты перетаскиваются из Навигатора; вставка разрешена только из своего репозитория и явно подключённых внешних каталогов. Соседние корни workspace не смешиваются.
- Двойной щелчок по связанному локальному узлу открывает карточку.
- После repository events перечитывается актуальная модель и обновляется подпись связанного узла. Изменение становится несохранённым снимком диаграммы; автоматической записи файла нет.
- Отсутствующие ссылки остаются на диаграмме и отмечаются в списке ссылок. Идентичность не подменяется другим объектом с похожим именем.
- `Workbench.onDiagramEvent` получает `document-changed`, `node-selected`, `node-activated`, `object-updated`, `reference-unresolved`, идентификатор репозитория, путь, а для узлов — cell ID и reference.
- Изменения подписи/геометрии диаграммы не записывают атрибуты объекта. Для изменения объекта используется карточка.

NRT означает доставку обновлений после событий и чтения репозитория, без жёсткой гарантии задержки. При недоступном backend обновления приостанавливаются. Отдельные будущие бизнес-функции требуют своих требований; они не считаются реализованными только из-за наличия событий.

Оформление систем теперь обновляется в обоих редакторах, включая изменения полей открытой карточки до сохранения. Draw.io получает ограниченный набор стилей через локальный мост; синхронизация отключается в настройках. Текущая страница обновляется сразу, остальные — при посещении. Подробные правила, тени, единицы толщины и ограничения: [Отображение систем](system-appearance.md).

## Пустые жгуты

Оба движка поддерживают нужную нотацию и нативное соединение мышью. Frade использует магнит тела фигуры, Draw.io — точку соединения или синюю направляющую стрелку. Фигура в палитре не нужна. Мост Draw.io помечает только новые соединения распознанных систем; старые линии не изменяются. Правила и ограничения: [empty-bundles.md](empty-bundles.md).
