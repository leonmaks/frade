# Отображение систем на диаграммах

Правила применяются в обоих редакторах к системам, перенесённым из навигатора, и к уже связанным системам открытых диаграмм при включённом обновлении. Прямоугольник без скругления. Остальные типы объектов сохраняют прежнее оформление.

## Настройки

Откройте шестерёнку «Настройки репозитория» → «Отображение элементов». Здесь редактируются цвета, толщина, параметры тени, точные идентификаторы типов и соответствие полей метаописания. Нажмите «Применить отображение». «По умолчанию» заполняет форму исходными значениями; для сохранения также нужно применение.

Это пользовательские настройки текущего локального профиля приложения, общие для его репозиториев; они сохраняются между запусками. Не записываются в файлы метаописания. В диаграммах сохраняются рассчитанные стили. Не требуется подключение к интернету.

## Правила по умолчанию

Сначала проверяется размещение «Внешняя», затем статус «Не целевая», затем тип изменений. Уточнения пользователя для нецелевых систем наследуются последовательно: сиреневый фон, пурпурный контур модифицируемой группы, толщина планируемой группы 2 pt.

| Условие                                | Фон     | Контур  | Толщина |
| -------------------------------------- | ------- | ------- | ------- |
| Внешняя, независимо от остальных полей | #DAE8FC | #6C8EBF | 1       |
| Не целевая                             | #E1D5E7 | #9673A6 | 1       |
| Не целевая + Модифицируется            | #E1D5E7 | #FF00FF | 1       |
| Не целевая + Планируется               | #E1D5E7 | #FF00FF | 2       |
| Используется / Разрабатывается         | #D5E8D4 | #82B366 | 1       |
| Планируется                            | #FFFF86 | #FF00FF | 2       |
| Модифицируется                         | #D5E8D4 | #FF00FF | 1       |
| Выводится из эксплуатации              | #BAC8D3 | #23445D | 1       |
| Остальные / не определено              | #F9F7ED | #363939 | 1       |

Толщина соответствует числу в поле pt интерфейса Draw.io: strokeWidth=1 или 2. Frade использует те же единицы модели, поэтому при масштабе 100% контуры визуально совпадают. Это единицы редактора, а не обещание физического размера в типографских пунктах на любом дисплее.

KA runtime использует тип sberea:kadzo.v2023.systems; также поддержан исходный kadzo.v2023.systems для каталогов. Поля: target-status, change-type, location, parent. Заполненный parent, включая структурированную ссылку ObjectRef, означает подсистему и отключает тень независимо от цветов и статусов. Само нахождение объекта во внешнем каталоге не означает location=Внешняя.

Внешний каталог может передавать необязательный объект attributes с этими полями. Старые каталоги продолжают работать; без характеристик используется правило неопределённого типа изменений. Внешние каталоги перечитываются вместе с обновлением репозитория; отдельная подписка на изменения файла каталога не реализована.

## Тень

Параметры закреплённого Draw.io 31.5.2 проверены в локальном js/app.min.js: mxConstants.SHADOWCOLOR=#000000, SHADOW_OPACITY=0.25, SHADOW_OFFSET_X=2, SHADOW_OFFSET_Y=3, SHADOW_BLUR=2. Его mxShape.createDropShadow создаёт CSS drop-shadow. В Draw.io используется родной shadow=1 и соответствующие параметры; в Frade — CSS drop-shadow с такими же смещением, размытием и непрозрачностью (округление альфа-канала до 8 бит). Frade сохраняет параметры в необязательном shadow узла JSON версии 1; старые файлы читаются без изменений.

[Документация Draw.io: настройка теней](https://www.drawio.com/docs/manual/styles/custom-shadows/) описывает включение эффекта и его параметры. В Frade тень применяется к телу прямоугольника; для непрозрачной заливки систем это соответствует ожидаемому виду. Различия сглаживания движков, масштаба, экспорта и режимов цветов не позволяют обещать пиксельную идентичность. Frade не воспроизводит автоматическую адаптацию цветов Draw.io к тёмной теме; исходные значения палитры остаются заданными в настройках.

## Обновление и ручное оформление

Оба редактора получают оформление из текущих характеристик карточки, включая её ещё не сохранённый черновик, и из обновлений репозитория. Данные объекта от этого не меняются. Диаграмма становится изменённой и сохраняется обычной командой. Сохранение диаграммы при несохранённой карточке может зафиксировать её предварительное оформление; используйте «Сохранить всё», чтобы сохранить оба документа.

Frade обновляет все связанные системы открытой диаграммы. Draw.io обновляет текущую страницу, а остальные — при переключении на них. Непосещённые страницы сохраняют прежнее оформление до открытия. Геометрия, связи и несвязанные стили сохраняются. Изменения стилей участвуют в Undo/Redo. Повторный рендер с теми же входными значениями не отменяет ручную правку или Undo; следующее изменение значимых характеристик или настроек заново применяет управляемые стили.

В Draw.io включено «Обновлять оформление из карточек в Draw.io». Отключите эту настройку для свободного ручного оформления: правила останутся только для новых переносов из навигатора. Повторное включение обновляет связанные системы по актуальным данным. За пределами Frade, например при открытии файла непосредственно в Draw.io, живой связи с карточками нет; обычные XML-стили и ссылки сохраняются.

Диаграммы только для чтения и неразрешённые ссылки не изменяются. Заблокированные фигуры Draw.io пропускаются. Обычные фигуры без ссылки на объект репозитория не затрагиваются. Настройка полей и типов позволяет адаптировать системную нотацию к другому метаописанию; универсальный конструктор правил для новых видов объектов пока не добавлен.

## Проверка

17 сценариев Electron прошли. Два новых сценария проверяют реальные действия через интерфейс для каждого формата: перенос, изменение полей до сохранения карточки, приоритет внешнего размещения, отключение тени у подсистемы, настройку палитры/толщины, сохранение файла и перезапуск, ручной режим Draw.io. Модульные тесты покрывают все ветви правил, безопасную сериализацию тени, восстановление настроек, изоляцию моста, отсутствие повторной перезаписи ручной правки и обновление при активации страницы.
