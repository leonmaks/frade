# Работа с диаграммами

В проводнике каждого репозитория первым дочерним узлом находится служебная папка `_diagrams` с отдельной иконкой. Она создаётся на диске при первой файловой операции. Правый щелчок по папке: «Новая папка…» или «Новая диаграмма…». В диалоге выберите Draw.io или Frade Draw. Допустимы вложенные папки, русские имена, пробелы и даты; действуют только ограничения файловой системы и защиты путей.

Один щелчок открывает preview-вкладку, двойной закрепляет. Вкладки можно переставлять и переносить между группами вместе с карточками. Документ имеет одну общую модель: если он открыт в нескольких группах, кнопка «Активировать диаграмму в этой группе» переносит живой редактор в выбранную группу, сохраняя изменения. Отдельного режима Draw в Desktop нет.

Ctrl+S сохраняет активный документ, Ctrl+Shift+S — все черновики. При закрытии действует общий выбор сохранения, отказа от сохранения или отмены закрытия. «Отменить изменения» перечитывает версию с диска. Восстанавливаются открытые файлы и порядок вкладок; незаписанные черновики не являются crash-recovery хранилищем.

Файлы проверяются по SHA-256 перед записью. Внешняя правка приводит к конфликту; черновик остаётся открыт. Изменения дерева и файлов проверяются каждые две секунды; чистый открытый документ обновляется с диска, грязный сохраняет свой черновик. Символические ссылки и выход за `_diagrams` запрещены. Запись производится через временный файл и атомарное переименование. Ревизии не заменяют координацию с несогласованным внешним процессом, который пишет в тот же момент.

## Добавление объектов

Перетащите объект мышью из левого Навигатора на канвас открытой диаграммы. Это одинаково работает для `.drawio` и `.frade`: узел появляется в точке сброса с учётом масштаба и смещения и сохраняет ссылку на объект. Вставку можно отменить через Undo. Отдельной панели «Объекты репозитория» в редакторах нет.

Допустимы объекты корня, которому принадлежит диаграмма, и явно подключённых к нему внешних каталогов. Сброс из другого корня отклоняется, даже при совпадающих ID. В режиме только чтения вставка недоступна. Список ссылок и предупреждения о пропавших объектах доступны через сворачиваемое меню «Ссылки на диаграмме» над канвасом.

## Внешний каталог

Контекстное меню корня в Навигаторе → «Подключить внешний каталог…» открывает системный выбор отдельного JSON-описания. Это не автоматический доступ к соседнему репозиторию. Каталог можно хранить независимо от репозиториев и подключать к нескольким из них. В workspace сохраняется ссылка на файл и его стабильный `id`; при Save As путь пересчитывается относительно workspace.

Подключённые каталоги появляются в дереве этого корня в разделе «Внешние источники». Их объекты перетаскиваются на канвас тем же способом.

Пример `services.catalog.json`:

```json
{
  "version": 1,
  "id": "shared-services",
  "label": "Внешние сервисы",
  "objects": [
    { "id": "payments-api", "name": "Платёжный API", "type": "service" },
    { "id": "architecture-concept", "name": "Понятие метамодели", "type": "metadata" }
  ]
}
```

Идентификаторы внутри одного каталога должны быть уникальны; файлы ограничены 1 МиБ и 5000 объектами. Совпадающие object ID в разных каталогах различаются по source ID. Каталог декларативный: он не исполняет код, не открывает произвольные файлы и не вызывает сервисы. Автоматическое превращение schema метамодели в каталог объектов или сетевой коннектор не подразумевается. Сервис/метаописание представляется явной записью каталога; дополнительные провайдеры можно развивать отдельно.
