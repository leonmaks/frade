# Diagram integration

`RepositoryBridge` depends only on domain/ports; its injected `RepositoryReader` can be an application session. Draw remains independently importable, editable and serializable without a repository. The bridge has no persistence command API: moving/resizing/recoloring/deleting a visual element cannot directly mutate domain objects.

`bindObject(elementId, ref)` and `bindRelation` create BOUND bindings with cached snapshots. Several element IDs can share a qualified entity reference. Visual edges need not be bound. `detach` retains cached content and visual overrides. `reconnect` compares revision/content: changed revision becomes STALE, same revision with conflicting content becomes CONFLICTED, missing source becomes UNRESOLVED. `reconcile` explicitly accepts a fresh snapshot and preserves visual overrides/geometry.

`resolveVisualAttributes` combines configured dependency rules with explicit local overrides; overrides win. `bridge.watchBinding(binding, rules, listener)` owns a disposable presentation controller. Its `current()` returns defensive binding/style values; subscribed entity changes refresh connected snapshots and non-overridden styling. `setVisual`, `detach`, `unbind`, `reconnect`, `reconcile` and `close` never invoke domain writes. DETACHED and UNBOUND ignore repository events; reconnect is explicit and reports STALE before accepting changed cached content through reconcile. UNBOUND retains an advisory cached reference, not an active subscription binding. Close unsubscribes and suppresses late asynchronous publication. Automatic Designer UI wiring is not implemented; no existing Designer shell was found.

The generic repository-diagram envelope stores the diagram plus bindings and delegates serialization to an injected codec. The integration test uses the existing public `@frade/draw/document` serializer/deserializer and proves round-trip/detached editing. No draw.io XML implementation was added to Repo Core. Existing Draw-only Save/Open format is unchanged; the wrapper is a separate optional format, not a silent migration of every diagram.
