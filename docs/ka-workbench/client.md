# Public Workbench client and backend composition

`@frade/repository-api/workbench` exports WorkspaceRoot/File/Status, MetadataSetProfile/Preview, SessionScope, RepositoryPresentation, WorkbenchClient and runtime decoders. Repository requests carry version 1. Events carry version 1, repository/session/model generation, monotonically increasing sequence and revision. Presentation includes rules, effective fields, source ownership, preserved sections and diagnostics. Object queries use normal bounded pages; the UI reads all pages and restarts a stale cursor against one revision.

`window.fradeWorkbench` exposes only `command`, `request`, `subscribe` and `onCloseRequested`. It does not expose ipcRenderer, Node, paths-as-requests or permissions. Main authenticates the sender and top frame. Add/Open/Browse use Main dialogs; metadata-path input is accepted only by its scoped host command. Main owns the workspace grants and ignores renderer-supplied roots during Save As. Preload copies bounded plain JSON without invoking getters and checks result/event/request shapes. The maximum transport JSON text is 8 MB, with the domain's depth/value bounds applied first.

`RepositoryBackend` in runtime-node owns the adapter registry and independent sessions. Main is a relay and settings/dialog host. Both legacy native IPC and Workbench operations execute in Utility. The explicit registry supports native v1/v2, sberea and injected factories. Renderer dependencies cannot reach these implementations; boundary tests cover imports and manifests.

An object/draft/tab identity is the qualified `(repositoryId, objectId)` tuple. A request additionally carries sessionId, generation and modelGeneration. Reopen invalidates old sessions; model changes invalidate old model generations. Cross-root top-level change sets and references are rejected. Core validates every embedded reference. Native workspace UUIDs are translated at the backend boundary while native on-disk identities remain unchanged.

The Main relay gives requests a 30-second deadline and cancels underlying work. A mutation timeout or child exit returns OUTCOME_UNKNOWN with operationId. Neither Main nor UI replays writes. Backend tracks in-flight/unknown operations and blocks model activation until reconciliation. A late response cannot complete another request or a replaced child. Root removal invalidates generations and releases that session's watchers. Shared metadata subscriptions remain independent.

UI always resynchronizes presentation and object pages after an accepted event, so a sequence gap triggers the same complete revision-coherent refresh; duplicate/out-of-order and old-session events are ignored. Unsubscribe guards already queued callbacks. Backend failure retains drafts and requires explicit root retry.

Candidate activation loads and validates before replacing a session, compares external type and reference-path mappings, checks the preview fingerprint again, and saves settings by fsynced staged file + rename. Persistence failure leaves the old binding. Failure to restore settings after a rejected activation closes the affected session until retry. Candidates are disposed on Cancel, replacement or root close.

`@frade/ui-navigator` exports pure `projectTree` and `Navigator`. Its keys include the repository and logical grouping; parent cycles/orphans are bounded buckets, never recursion loops. Type and file projections share entity references. `@frade/ui-inspector` exports `ObjectInspector`: it accepts rule/objects/attributes/raw-input/issues and emits edits; it has no persistence authority. `@frade/ui-workspace` exports Workbench plus pure draft/tab/layout functions, owns shared drafts and composes the leaf packages. Styles and Codicons are a separate public CSS export.

The adapter intentionally updates existing objects in one source file per atomic command. Cross-file atomic changes, direct derived-edge writes and alias/tag-preserving mutation are not offered as supported actions. Unknown sections remain read-only and survive normal card saves. Recovery acknowledges observed source state and retains evidence; it never guesses or replays a write.
