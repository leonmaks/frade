# KA Workbench

Desktop открывает исходный KA и редактирует существующие карточки через формы. Данные читает и сохраняет Utility backend; renderer не имеет файлового API.

## Запуск и открытие KA

Из корня проекта:

```powershell
pnpm install --frozen-lockfile
pnpm --filter @frade/desktop build
pnpm start:desktop
```

1. Нажмите **Открыть KA**.
2. Выберите папку с `root.yaml`: для предоставленного набора это `E:/sber.wsp/ka_dzo/KA`.
3. Выберите папку метаописания: `E:/sber.wsp/ka_dzo/_ecosystems_`.
4. После загрузки проводник показывает **138 объектов / 19 типов**. Найдите объект по имени или ID, нажмите на него и меняйте поля справа.
5. **Ctrl+S** сохраняет активную карточку в её исходный YAML. Повторное открытие читает подтверждённое значение с диска.

Автоматические тесты всегда создают отдельные копии. Оригиналы не используются для тестовой записи. Альтернативные источники тестов задаются `FRADE_KA_DATA_ROOT` и `FRADE_KA_META_ROOT`.

## Карточки

Одиночный щелчок открывает preview, двойной щелчок или изменение закрепляет вкладку. Черновик общий для всех групп одной карточки и независим для одинаковых ID в разных репозиториях. Ctrl+W закрывает вкладку, Ctrl+Tab переключает вкладки, кнопка разделения открывает второй вид того же черновика. Перетаскивание переставляет вкладки и переносит их между группами.

Форма поддерживает текст, числа, enum, boolean, календарную дату, вложенные объекты, массивы и ссылки. Некорректный числовой ввод остаётся видимым и блокирует Save. «Убрать значение», `null`, пустая строка, ноль и false имеют разный смысл. Defaults появляются только при явном добавлении значения. Дополнительные исходные атрибуты показаны отдельной группой и сохраняются вместе с известными полями.

Выбор ссылки фильтрует допустимые типы и показывает результаты порциями по 50. Не найденная исходная ссылка остаётся видимой до осознанного изменения. Переход по ссылке открывает карточку и раскрывает её путь. Раздел «Источник и метаописание» показывает принадлежность файлу и историческое дополнение tech_params.

Исходные ошибки KA показаны в панели «Проблемы». Repair policy разрешает правку, не добавляющую и не ухудшающую ошибки; новые невалидные значения backend отклоняет. Ограничения и условная обязательность проверяются также при сохранении. Вкладка «Исходные разделы» показывает `sber` и неизвестные коллекции без редактирования.

## Несколько репозиториев и workspace

Через Файл или **Ctrl+Shift+P** доступны Add KA, Add native, Open Workspace, Save Workspace As и Save All. Контекстное меню корня позволяет переименовать его, настроить модель, перезагрузить или убрать из workspace. Корни перетаскиваются для смены порядка. Повторный выбор одной физической папки активирует имеющийся корень.

`.frade-workspace` версии 1 сохраняет UUID, порядок, подписи, adapter kind, пути данных и именованные наборы моделей. Save As перебазирует относительные пути от новой папки. Недоступность одного корня не останавливает остальные. Remove не удаляет данные и обрабатывает несохранённые карточки только этого корня.

Сохранение определяется активной карточкой, даже если в дереве выбран другой корень. Save All выполняет независимые операции последовательно и показывает число успехов и ошибок; общей транзакции между файлами или репозиториями нет.

## Метаописание

Контекстное меню корня → **Настройки метаописания**. Можно ввести путь, выбрать Browse, добавить/переименовать набор, изменить entries и удалить неактивный набор. Относительный путь папки считается от сохранённого workspace; entries — от папки метаописания.

**Проверить набор** загружает candidate и показывает fingerprint, изменённые определения и исходные диагностики. **Применить** атомарно сохраняет настройки и меняет только выбранную сессию. Cancel, невалидный candidate или ошибка сохранения настроек оставляют прежнюю модель. Dirty-карточки требуют Save/Discard/Cancel, а незавершённая запись или неизвестный исход блокируют переключение.

Базовый набор: `kadzo/v2025/entities/root.yaml` плюс `kadzo/v2023/entities/technical/tech_params.yaml`; документация — четыре `docs/metamodel/kadzo-*.md` из профиля. Внешние имена `kadzo.v2023.*` в данных не переименовываются. Приоритет подписей и help: явная schema → отсутствующие значения из таблиц docs/metamodel → исходный ключ. Markdown/HTML отображаются текстом. Fingerprint учитывает логические входы, схемы и документацию, но не абсолютную папку.

## Конфликты и восстановление

Внешнее изменение чистой карточки обновляет её. Для dirty-карточки показывается таблица «исходное / черновик / на диске». Можно принять диск или явно перепроверить черновик относительно новой ревизии. Смена схемы тоже требует перепроверки. Save не перезаписывает конфликт автоматически.

При неизвестном исходе Save повторная мутация не отправляется: используйте **Выяснить исход**. После остановки backend черновики остаются в окне, а корни требуют **Повторить**. Если сохранён журнал прерванной записи, **Проверить восстановление** показывает состояние файла; подтверждение сохраняет свидетельства операции и не переписывает YAML. Конфликтующее свидетельство нельзя подтвердить автоматически.

При закрытии вкладки, удалении корня, замене workspace, смене модели и выходе действует Save/Discard/Cancel. Неудачный Save не закрывает карточку. Черновики живут в памяти окна; вкладки, выбор, раскрытие дерева и размеры панелей восстанавливаются из локальных настроек. Draw доступен через Activity Bar и сохраняет состояние при переключении разделов.
